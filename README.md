# 🎲 מרוץ על לוח שש-בש

משחק מרוץ על לוח שש-בש: אין אכילה, וטבליה אחת חוסמת נקודה. הוא בנוי ב-HTML, CSS ו-JavaScript בלבד, בלי ספריות ובלי שלב בנייה. אפשר לשחק נגד המחשב או שני שחקנים על מכשיר אחד.

## חוקי המשחק בקצרה
- כל 15 הטבליות של כל שחקן מתחילות בפינה הימנית-עליונה שלו. שני השחקנים נעים נגד כיוון השעון אל הבית, שהוא הפינה הימנית-תחתונה של כל שחקן.
- **פתיחה:** כל שחקן מטיל קובייה, והגבוה פותח.
- **טבליה בודדה:** בהתחלה מזיזים רק טבליה אחת, עד שהיא נכנסת לבית. רק אז אפשר להזיז את שאר הטבליות.
- **חסימה ברצף:** מותר להחזיק עד 5 נקודות ברצף. 6 ברצף מותר רק למי שיש לו שתי נקודות צמודות בבית.
- **דאבל הפוך:** החוק פעיל מרגע ששני השחקנים נכנסו לבית. בדאבל משחקים קודם את הדאבל ואחריו את ההופכי שלו (1-1 ואז 6-6, 2-2 ואז 5-5, 3-3 ואז 4-4).
- **4-3:** גם זה פעיל רק אחרי ששני השחקנים נכנסו לבית. קודם משחקים 4-3, אחר כך בוחרים דאבל אחד, ואחריו מקבלים זריקה נוספת.
- **גניבת קוביות:** שחקן חסום מעביר ליריב את הקוביות שלא הצליח לשחק. היריב משחק אותן וממשיך בתור שלו.
- מוציאים טבליות רק כשכל ה-15 בבית. מי שמוציא ראשון את כל הטבליות מנצח, ואם ליריב לא יצאה אף טבליה זה מרס.

## הרצה מקומית
פותחים את `index.html` בדפדפן בלחיצה כפולה, ולא צריך שרת.
גופן Heebo נטען מ-Google Fonts. בלי אינטרנט המשחק עובד כרגיל עם גופן המערכת.

## העלאה ל-GitHub ו-GitHub Pages
1. יוצרים מאגר ריק חדש ב-GitHub בשם `shesh-besh-race`, ציבורי ובלי README.
2. מריצים בטרמינל מתוך התיקייה (מחליפים את `USERNAME` בשם המשתמש שלכם):
   ```bash
   git init
   git add .
   git commit -m "Shesh-besh race game"
   git branch -M main
   git remote add origin https://github.com/USERNAME/shesh-besh-race.git
   git push -u origin main
   ```
3. ב-GitHub נכנסים ל-**Settings ← Pages**. תחת **Source** בוחרים **Deploy from a branch**, ואז ענף `main` ותיקייה `/ (root)`, ולוחצים **Save**.
4. אחרי דקה או שתיים המשחק זמין בכתובת:
   `https://USERNAME.github.io/shesh-besh-race/`
