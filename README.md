# 🎲 מרוץ על לוח שש-בש – גרסת התנסות

משחק מרוץ על לוח שש-בש: בלי אכילה, וטבליה אחת חוסמת נקודה. בנוי ב-HTML, CSS ו-JavaScript בלבד, בלי ספריות ובלי שלב בנייה.

בגרסת ההתנסות פתוחות רמת הקושי **קל** וערכת העיצוב **עץ ולבד**.
הגרסה המלאה (PRO) כוללת 3 רמות קושי ו-4 עיצובי לוח, וזמינה ב-itch.io.

## חוקי המשחק בקצרה
- **טבליה בודדה פותחת:** כל 15 הטבליות מתחילות בפינה הימנית-עליונה. רק טבליה אחת רצה, עד שהיא נכנסת לבית.
- **בלי אכילה – טבליה אחת חוסמת:** מותר עד 5 חסימות ברצף. 6 ברצף מותר רק למי שיש לו זוג נקודות צמודות בבית.
- **דאבל הפוך:** אחרי ששני השחקנים בבית, משחקים את הדאבל ואחריו את ההופכי שלו. ב-4-3 משחקים 4-3, בוחרים דאבל אחד ומקבלים זריקה נוספת.
- **גניבת קוביות:** שחקן חסום מעביר ליריב את הקוביות שלא שוחקו.

## קישור לגרסה המלאה
בשורות הראשונות של `app.js`:
```js
const PRO_STORE_URL = 'https://YOUR-NAME.itch.io/shesh-besh-race-pro';
```

## הרצה מקומית
פותחים את `index.html` בדפדפן, ולא צריך שרת.

## העלאה ל-GitHub ו-GitHub Pages
```bash
git init
git add .
git commit -m "Shesh-besh race demo"
git branch -M main
git remote add origin https://github.com/USERNAME/shesh-besh-race.git
git push -u origin main
```
אחר כך ב-GitHub נכנסים ל-**Settings ← Pages**, בוחרים **Deploy from a branch**, ענף `main` ותיקייה `/ (root)`, ולוחצים **Save**.
המשחק יהיה זמין בכתובת `https://USERNAME.github.io/shesh-besh-race/`
